# Contribuer à AKORIS

## Configuration Git Obligatoire

Avant toute contribution (ou exécution d'agent), l'identité Git doit être configurée avec l'adresse associée au compte GitHub. Les plateformes de déploiement (comme Vercel) rejettent les commits dont l'adresse e-mail est invalide ou non associée.

```bash
git config user.name "Oulai Sieni Tarek"
git config user.email "sieni7@gmail.com"
```

## Developer Certificate of Origin (DCO)

Toute contribution doit être signée (Signed-off-by). Cela certifie que vous avez le droit de soumettre le code sous la licence du projet.

Ajoutez la ligne suivante à la fin de chaque message de commit :

`Signed-off-by: Prénom Nom <email@exemple.com>`

Utilisez `git commit -s` pour l'ajouter automatiquement.
